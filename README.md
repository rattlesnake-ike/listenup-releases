# ListenUp — downloads

**[Download ListenUp 1.0.3](https://github.com/rattlesnake-ike/listenup-releases/releases/download/v1.0.3/ListenUp-1.0.3.zip)**

1. Open the zip, drag **ListenUp** to your Applications folder.
2. The first time only: right-click ListenUp → **Open** → **Open**.
3. Allow the Microphone and Speech Recognition when asked.
4. Turn on Dictation: System Settings → Keyboard → Dictation. ListenUp needs it to hear you.

After that it updates itself. Needs macOS 10.15 or newer.
